| [resource-monitor.md](resource-monitor.md) | リソース モニター（待ち受けポート、モジュール）          |

そのほかの画面（パフォーマンス・スタートアップ・サービス・設定）の手順は `tests/e2e/native/app.test.mjs` にある。足すときは、このフォルダーに 1 ファイル足して表に載せる。
