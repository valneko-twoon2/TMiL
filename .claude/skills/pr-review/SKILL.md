# PR レビュー

レビューは PR のときだけ行う。対象はソースコードだけ。

## 対象

- 見る: `src/frontend/**`・`src/backend/**` の本体
- 見ない: テスト（`*.test.ts`・`tests/`・Rust の `mod tests` の中）、ドキュメント（`*.md`・`docs/`）、設定・CI・スクリプト、スナップショット、ロックファイル

対象のファイルが無ければ、テンプレートの「対象のファイルはありませんでした」の形で投稿して終わる。

## 手順

1. 対象のファイルを確かめる

   ```sh
   gh pr diff <PR番号> --name-only
   ```

2. Skill ツールで `code-review` を呼ぶ。引数は `medium <PR番号>`（`--comment` は付けない）
3. 出てきた指摘から、対象外のファイルへの指摘と、好みの問題を外す
4. [template.md](template.md) の形にまとめる
   - 平易な文で、1 件 1〜2 行。細かくなりすぎない
   - 「直したほうがよい」は実害があるものだけ。それ以外は「気になった点」へ
   - 指摘が無ければ「問題は見つかりませんでした。」とだけ書き、表は消す
5. 一時ファイルに書いて投稿する

   ```sh
   gh pr comment <PR番号> --body-file <ファイル>
   ```

6. 利用者には、指摘の件数と重要なものだけを短く伝える
