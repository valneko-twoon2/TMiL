# リソース モニター

本家の Windows ではタスク マネージャーの奥（パフォーマンス タブの下）にあるので、サイドバーに並べています。パフォーマンス タブの「リソース モニターを開く」からも移れます。

## タブ

| タブ         | 表                                                                                                   | 右のグラフ                          |
| ------------ | ---------------------------------------------------------------------------------------------------- | ----------------------------------- |
| 概要         | CPU・ディスク・ネットワーク・メモリのプロセス                                                        | CPU・ディスク・ネットワーク・メモリ |
| CPU          | プロセス（スレッド・ハンドル・平均 CPU）・サービス・関連付けられたハンドル・関連付けられたモジュール | CPU 全体と論理プロセッサごと        |
| メモリ       | プロセス（コミット・ワーキング セット）・物理メモリの構成                                            | メモリ                              |
| ディスク     | 読み書きしているプロセス・記憶域                                                                     | ディスク全体と 1 台ごと             |
| ネットワーク | 接続のあるプロセス・TCP 接続・リッスン ポート                                                        | ネットワーク全体と 1 つごと         |

## チェックで絞り込む

プロセスにチェックを付けると、そのプロセスの行が表の上に並び、サービス・モジュール・TCP 接続・リッスン ポートがそのプロセスのものだけになります。CPU のグラフには、チェックしたプロセスの合計（橙）が重なります。チェックはタブをまたいで残ります。

右クリックでプロセスの終了・ツリーの終了・中断・再開・オンライン検索ができます。

## ファイルを開いているプロセスを探す

CPU タブの「関連付けられたハンドル」に場所を入れて検索すると、それを開いているプロセスが並びます。「USB メモリを取り外せない」「ファイルを消せない」ときに、どのプロセスが掴んでいるかを調べるのに使います。

| OS      | 入れるもの                 | 調べ方                                                                                                            |
| ------- | -------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Windows | ファイルかフォルダーの場所 | Restart Manager（`RmGetList`）。フォルダーは中のファイル（5000 個まで）を調べる。100 個までならファイルごとに出す |
| Linux   | ファイルの名前や場所の一部 | `/proc/<pid>/fd` のリンク先に、入れた文字を含むもの（大文字小文字は区別しない）                                   |

Windows では、フォルダーそのものを開いているだけのプロセス（エクスプローラーで開いている など）は出ません。権限の足りないプロセスは、どちらの OS でも出ないことがあります。

## ポートやアドレスで絞り込む

ネットワーク タブの上の欄に数字を入れると、そのポート（ローカルかリモート）の接続・待ち受けと、そのプロセスだけが残ります（`:443` のように「:」を付けても同じ）。数字以外はアドレス・イメージ名・PID の一部で絞り込みます。「ポート 3000 を使っているのは誰か」を調べるのに使います。

## 値の取り方

| 値             | 取り方                                                                            |
| -------------- | --------------------------------------------------------------------------------- |
| 平均 CPU       | 直近 60 秒の計測の平均（画面側で持つ）                                            |
| 接続・待ち受け | Windows は `netstat -ano`、Linux は `/proc/net/{tcp,udp}{,6}`。2 秒ごとに読み直す |
| モジュール     | Windows は PowerShell の `Get-Process`、Linux は `/proc/<pid>/maps`               |
| ハンドル       | 上の「ファイルを開いているプロセスを探す」のとおり。検索したときだけ読む          |
| スレッド       | Linux のみ（`/proc/<pid>/stat`）。Windows では取れない                            |

Linux では、ほかのユーザーのプロセスの接続は PID が分かりません（「不明」と出ます）。
