# リソース モニター

本家の Windows ではタスク マネージャーの奥（パフォーマンス タブの下）にあるので、サイドバーに並べています。パフォーマンス タブの「リソース モニターを開く」からも移れます。

## タブ

| タブ         | 表                                                                           | 右のグラフ                          |
| ------------ | ---------------------------------------------------------------------------- | ----------------------------------- |
| 概要         | CPU・ディスク・ネットワーク・メモリのプロセス                                | CPU・ディスク・ネットワーク・メモリ |
| CPU          | プロセス（スレッド・ハンドル・平均 CPU）・サービス・関連付けられたモジュール | CPU 全体と論理プロセッサごと        |
| メモリ       | プロセス（コミット・ワーキング セット）・物理メモリの構成                    | メモリ                              |
| ディスク     | 読み書きしているプロセス・記憶域                                             | ディスク全体と 1 台ごと             |
| ネットワーク | 接続のあるプロセス・TCP 接続・リッスン ポート                                | ネットワーク全体と 1 つごと         |

## チェックで絞り込む

プロセスにチェックを付けると、そのプロセスの行が表の上に並び、サービス・モジュール・TCP 接続・リッスン ポートがそのプロセスのものだけになります。CPU のグラフには、チェックしたプロセスの合計（橙）が重なります。チェックはタブをまたいで残ります。

右クリックでプロセスの終了・ツリーの終了・中断・再開・オンライン検索ができます。

## 値の取り方

| 値             | 取り方                                                                            |
| -------------- | --------------------------------------------------------------------------------- |
| 平均 CPU       | 直近 60 秒の計測の平均（画面側で持つ）                                            |
| 接続・待ち受け | Windows は `netstat -ano`、Linux は `/proc/net/{tcp,udp}{,6}`。2 秒ごとに読み直す |
| モジュール     | Windows は PowerShell の `Get-Process`、Linux は `/proc/<pid>/maps`               |
| スレッド       | Linux のみ（`/proc/<pid>/stat`）。Windows では取れない                            |

Linux では、ほかのユーザーのプロセスの接続は PID が分かりません（「不明」と出ます）。
