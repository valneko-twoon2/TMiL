# ドキュメント

種類ごとにフォルダーを分けています。中身は各フォルダーの README を見てください。

| フォルダー                    | 内容                                                       |
| ----------------------------- | ---------------------------------------------------------- |
| [architecture](architecture/) | 設計。全体の構成、バックエンドの状態機械、フロントとの契約 |
| [development](development/)   | 開発の進め方。環境構築、ブランチとコミット、Lint           |
| [testing](testing/)           | テスト。種類と回し方、分類の付け方、件数の集計             |
| [ci](ci/)                     | CI。回すもの、PR レビュー、依存関係の管理                  |
| [release](release/)           | リリースの手順                                             |
| [features](features/)         | 個別の機能の説明                                           |

書き方と置き方は `.claude/skills/docs` にあります。
